# Course dataset

`tourist_arrivals.csv` is the original export downloaded from the dataset folder linked by the lab handout:

https://drive.google.com/drive/folders/1b8KgyEbT1E6EkpEEKOkiOe29JnHLFbml?usp=sharing

The first two rows are titles; the third is the real header. The loader handles both this export and an ordinary CSV starting with the header. The file contains 314 records and 19 columns, including two duplicate monthly dates.

The project preserves the source bytes. See `results/run_details.json` for the SHA-256 checksum of the supplied file. No source measurements are presented as independently verified official statistics. Follow your course's rules before redistributing the data in a public repository.
